# Website Preview Guide

## 🌐 Access the Website

The development server should be running on: **http://localhost:8080**

## 📱 Features to Preview

### 1. **Login/Signup Page** (`/auth`)
- **Animated Background**: Floating particles with glassmorphism effect

- **Form**: Login/Signup toggle with smooth transitions
- **Animations**: 
  - Fade-in and zoom-in animations
  - Floating particles
  - Gradient buttons with hover effects

### 2. **Dashboard** (`/`)
After logging in, you'll see:
- **AI Based Summary Card**:
  - Animated statistics (Total Sales, Items Sold, Revenue)
  - Numbers animate on page load
  - AI Insights section with recommendations
  - Hover effects and transitions

- **Interactive Cards**:
  - Pie chart with animations
  - Top Selling Product card with pulsing icons
  - Overview card with bouncing chevron
  - All cards have hover scale effects

- **Action Buttons**:
  - UPI (BHIM) button
  - Access & Controls button
  - WhatsApp Business button
  - All buttons have hover animations

### 3. **Header Features**
- **Update & Create Buttons**: Rounded buttons with icons
- **Search Bar**: 
  - Functional search with toast notifications
  - Gradient search icon button
  - Enter key support
- **Language Selector**: 
  - Dropdown with 6 languages
  - Flag icons and native names
  - Selected language indicator
- **XyroAi Voice Assistant**:
  - Click to open chat interface
  - Speech recognition
  - AI-powered responses
  - Message history
- **Background Selector**: Change website background
- **Theme Switcher**: Toggle themes
- **User Menu**: Profile dropdown with logout

### 4. **Sidebar Navigation**
- Radio button style navigation
- Hover scale effects
- Active state highlighting
- Smooth transitions

## 🚀 How to Test

1. **Start the Server**:
   ```bash
   cd image-intent-builder-main
   npm run dev
   ```

2. **Open Browser**:
   - Navigate to `http://localhost:8080`
   - You'll be redirected to `/auth` if not logged in

3. **Login/Signup**:
   - Enter any email and password (demo mode)
   - Click "Login" or "Sign Up"
   - You'll be redirected to the dashboard

4. **Test Features**:
   - Click on language selector to see dropdown
   - Click on XyroAi button to test voice assistant
   - Try the search bar
   - Change background using background selector
   - Hover over cards to see animations
   - Navigate between pages using sidebar
